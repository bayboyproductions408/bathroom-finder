Support

We read everything that comes in.

Fastest route: Profile → Send feedback inside the app. It tells us which screen you were on, which usually saves a round of questions.

Email:

Reporting something harmful? Say so in the subject line and it gets looked at first.

Report a photo, review or listing

Every photo and listing in the app has a report control. A reported photo is taken down immediately and re-reviewed by a person before it can reappear. Reported listings are flagged for everyone once two different people report them.

If something needs removing urgently, email us and include a link or the name of the place.

Common things

The map is empty

Zoom in — the app only loads bathrooms once you are close enough for the results to be useful. If it still looks empty, tap Search this area.

It will not use my location

Browsers only give location to secure (https) pages. If you added the app to your home screen from an https address this works normally. Otherwise check Settings → Safari → Location on iPhone.

The first load is slow

The server sleeps when nobody has used it for a while, so the first request after a quiet spell can take up to a minute. After that it is quick.

A bathroom is in the wrong place, or gone

Open it and use Report a problem. You can move the pin, fix the hours, or mark it closed. Corrections take effect straight away.

I want my data deleted

In the app: Profile → Erase everything on this device. For data on our server, email us — see Privacy.

Known limits right now

  • The bathroom rental feature is a prototype. No money moves, and there is no identity verification. Do not use it with strangers.
  • Photos wait for human review before anyone else sees them, so they do not appear instantly.
  • This is an early release and the database may be reset.
